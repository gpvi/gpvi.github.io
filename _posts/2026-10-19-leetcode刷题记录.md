## 从 0 到 n 数字中 2 的个数

### 题目思路

#### 1. 暴力法

从 0 到 n 遍历每一个数字，对每一个数字的每一位进行判断。

#### 2. 通过数学规律优化

![image-20240319203243823](/assets/posts/%E4%BB%8E0%E5%88%B0n%E6%95%B0%E5%AD%97%E4%B8%AD2%E7%9A%84%E4%B8%AA%E6%95%B0/image-20240319203243823.png)

计算十位数字为 2 的数字个数。设当前位为 d，高位为 ab，低位为 c：

1. 当 d < 2 时，十位为 2 的个数是 `(ab - 1 + 1) * 10^(2 - 1)`。
2. 当 d = 2 时，十位为 2 的个数是 `ab * 10 + 1 + c`。
3. 当 d > 2 时，十位为 2 的个数是 `(ab + 1) * 10^(2 - 1)`。

```cpp
#include <iostream>

int countTwos(int n) {
    int count = 0;
    for (long long digit = 1; n / digit > 0; digit *= 10) {
        int high = n / (digit * 10);
        int cur = (n / digit) % 10;
        int low = n % digit;

        if (cur < 2) {
            count += high * digit;
        } else if (cur == 2) {
            count += high * digit + low + 1;
        } else {
            count += (high + 1) * digit;
        }
    }
    return count;
}

int main() {
    int n;
    std::cout << "Enter a number n: ";
    std::cin >> n;

    int result = countTwos(n);
    std::cout << "Number of times 2 appears from 0 to " << n << " is: " << result << std::endl;

    return 0;
}
```

## 77. 组合

[77. 组合 - 力扣（LeetCode）](https://leetcode.cn/problems/combinations/description/)

算法复习：回溯。

回溯模板：

```text
void func(flag, mem, cur)

resType in() {
    func(initflag, initmem, cur)
}
```

### 题目分析

1. 组合具有唯一性。
2. 组合内数字不重复。
3. 各个组合各不相同，不存在不同组合内部数字相同的情况。

### 解法一

```cpp
class Solution {
public:
    void get_combaition(vector<int>& cur, int index, vector<vector<int>>& res,
                        int count, bool* arr, int n, int k) {
        if (count == k) {
            res.push_back(cur);
            return;
        }
        if (index > n)
            return;

        for (int i = index; i <= n; i++) {
            if (arr[i] == 0) {
                cur.push_back(i);
                arr[i] = 1;
                count++;
                get_combaition(cur, i + 1, res, count, arr, n, k);
                cur.pop_back();
                arr[i] = 0;
                count--;
            }
        }
    }
    vector<vector<int>> combine(int n, int k) {
        vector<vector<int>> res;
        vector<int> cur;
        bool arr[n + 1];
        memset(arr, 0, n + 1);
        get_combaition(cur, 1, res, 0, arr, n, k);
        return res;
    }
};
```
